# Clawture Premium Shopify Theme 💅✨

Welcome to the official repository for the custom **Clawture** Shopify theme. This theme is highly optimized, customized, and styled to match the unique aesthetic of the Clawture brand (premium press-on nails).

## 🌟 Features & Customization
- **Custom Aesthetic Branding**: Pre-configured with HSL curated color palettes matching Clawture's styling (warm nudes, soft borders, and premium buttons).
- **Responsive Layouts**: Designed to look stunning on both desktop and mobile viewports.
- **Optimized Sections**: Includes custom testimonials, featured collections, video reviews, and promotional grids tailored to product showcases.
- **Custom CSS Adjustments**: Hides standard platform tags and templates to keep the design clean, premium, and focused on customer conversion.

---

## 📂 Folder Structure
* `assets/` - Contain theme stylesheet (`theme.css`), JavaScript behavior (`theme.js`), and asset libraries.
* `config/` - Configuration data for settings, layouts, and translations schema.
* `layout/` - Theme skeleton layout Liquid templates (theme layout, password template, etc.).
* `locales/` - Language translation files for internationalized text.
* `sections/` - Modular, customizable block components for layout styling.
* `snippets/` - Reusable code segments for themes, menus, and products.
* `templates/` - Route-based JSON and Liquid templates.

## 🚀 Installation & Setup
To upload this theme directly to your Shopify store:

1. **Recompress the files**: Ensure all folders (`assets`, `config`, etc.) are compressed at the root level of a `.zip` archive (e.g., `Clawture-Theme.zip`).
2. **Shopify Admin**:
   - Go to your **Shopify Admin Dashboard**.
   - Navigate to **Online Store** > **Themes**.
   - Under the **Theme library** section, click **Add theme** > **Upload zip file**.
   - Choose the compiled `theme_export__clawture-in-clawture-v1-0-0__19AUG2026-0354pm.zip` file and click **Upload**.
3. **Publish**: Once uploaded, click **Actions** next to the theme name, then **Publish**.
